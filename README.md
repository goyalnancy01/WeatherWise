# 🌦️ WeatherWise

WeatherWise is a simple and elegant web application that allows users to get real-time weather updates for any city in the world. Powered by OpenWeatherMap API, it helps users check current temperature, humidity, wind speed, and general weather conditions.

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature, humidity, and wind data
- ☀️ Dynamic weather icons based on live conditions
- 📱 Responsive design for all devices
- 🎨 Simple and clean UI

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **OpenWeatherMap API**
